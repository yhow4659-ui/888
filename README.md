# موقع أماني — حديقة الحكايات

هذه حزمة ملفات الموقع المعدّل. أبقِ `index.html` و`styles.css` ومجلدي `scripts/` و`site-images/` معًا كما هي.

## تشغيله محليًا

يتطلب الموقع خادم ملفات محليًا لأن مسارات الصور والأنماط تبدأ من جذر الموقع. بعد فك الضغط، افتح الطرفية داخل هذا المجلد وشغّل:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000` في المتصفح.

تحتوي الحزمة على المشاهد والصور والتفاعلات التي نُقلت من الموقع المرجعي، مع تغيير الاسم إلى «أماني». لم تُنشر الحزمة على GitHub.
